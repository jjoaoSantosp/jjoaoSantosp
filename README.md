## 📌 Um projeto que representa bem meu momento atual

### 🎸 Casa 2 Studio

Um sistema web desenvolvido para um estúdio musical, pensado para resolver um problema real: **organizar o agendamento dos ensaios**.

O projeto começou como uma ideia simples e acabou se tornando uma oportunidade para trabalhar conceitos que eu queria realmente entender na prática.

**Algumas coisas que trabalhei no projeto:**

- Cadastro e gerenciamento de usuários
- CRUD de agendamentos
- Validação de horários
- Prevenção de conflitos entre reservas
- Regras de negócio
- API com Node.js e Express
- Persistência de dados
- Prisma como ORM
- Versionamento com Git e GitHub
